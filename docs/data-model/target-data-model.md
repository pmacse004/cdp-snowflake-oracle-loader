## 2. CDP_APP Schema — Business Tables

### 2.1 CDP_APP.REF_CODE_VALUE

Target reference / code-value table.

```sql
CREATE TABLE CDP_APP.REF_CODE_VALUE (
    CODE_ID           NUMBER(10)    NOT NULL,
    CODE_DOMAIN       VARCHAR2(50)  NOT NULL,
    CODE_VALUE        VARCHAR2(30)  NOT NULL,
    CODE_LABEL        VARCHAR2(100) NOT NULL,
    SORT_ORDER        NUMBER(5),
    IS_ACTIVE         NUMBER(1)     NOT NULL DEFAULT 1,  -- 1=active, 0=inactive
    SOURCE_CODE_ID    NUMBER(10)    NOT NULL,
    CREATED_AT        TIMESTAMP     NOT NULL,
    CREATED_BY        VARCHAR2(100) NOT NULL,
    UPDATED_AT        TIMESTAMP     NOT NULL,
    UPDATED_BY        VARCHAR2(100) NOT NULL,
    CONSTRAINT PK_REF_CODE_VALUE    PRIMARY KEY (CODE_ID),
    CONSTRAINT UQ_CODE_DOMAIN_VALUE UNIQUE (CODE_DOMAIN, CODE_VALUE)
);
```

**Business key (MERGE key):** `(CODE_DOMAIN, CODE_VALUE)`

### 2.8 CDP_APP.MONTHLY_USAGE

```sql
CREATE TABLE CDP_APP.MONTHLY_USAGE (
    USAGE_ID                   NUMBER(15)    NOT NULL,
    SOURCE_USAGE_ID            NUMBER(15)    NOT NULL,
    ENERGY_ACCOUNT_ID          NUMBER(15)    NOT NULL,   -- FK → ENERGY_ACCOUNT (target)
    PREMISE_ID                 NUMBER(15)    NOT NULL,   -- FK → SERVICE_PREMISE (target)
    METER_ID                   NUMBER(15)    NOT NULL,   -- FK → METER (target)
    BILLING_MONTH              VARCHAR2(7)   NOT NULL,   -- YYYY-MM
    BILL_START_DATE            DATE          NOT NULL,
    BILL_END_DATE              DATE          NOT NULL,
    BILLING_DAYS               NUMBER(3)     NOT NULL,
    KWH_USAGE                  NUMBER(12,6)  NOT NULL,
    PEAK_DEMAND_KW             NUMBER(10,6),
    PREV_METER_READING         NUMBER(12,6)  NOT NULL,
    CURR_METER_READING         NUMBER(12,6)  NOT NULL,
    RATE_PLAN                  VARCHAR2(20)  NOT NULL,
    ENERGY_CHARGE              NUMBER(15,2)  NOT NULL,
    TAX_AMOUNT                 NUMBER(10,2)  NOT NULL,
    TOTAL_BILLED_AMOUNT        NUMBER(15,2)  NOT NULL,
    CALCULATED_BILL_TOTAL      NUMBER(15,2)  NOT NULL,   -- derived: ENERGY_CHARGE + TAX_AMOUNT
    BILL_TOTAL_VARIANCE        NUMBER(10,2),             -- source total - calculated total
    READ_TYPE                  VARCHAR2(1)   NOT NULL,   -- A / E
    CORRECTION_FLAG            VARCHAR2(1)   NOT NULL DEFAULT 'N',
    ORIGINAL_SOURCE_USAGE_ID   NUMBER(15),
    SOURCE_UPDATED_AT          TIMESTAMP     NOT NULL,   -- for correction dedup
    CREATED_AT                 TIMESTAMP     NOT NULL,
    CREATED_BY                 VARCHAR2(100) NOT NULL,
    UPDATED_AT                 TIMESTAMP     NOT NULL,
    UPDATED_BY                 VARCHAR2(100) NOT NULL,
    CONSTRAINT PK_MONTHLY_USAGE         PRIMARY KEY (USAGE_ID),
    CONSTRAINT UQ_USAGE_SRC_ID          UNIQUE (SOURCE_USAGE_ID),
    CONSTRAINT UQ_USAGE_BIZ_KEY         UNIQUE (ENERGY_ACCOUNT_ID, BILLING_MONTH),
    CONSTRAINT FK_USAGE_ENERGY_ACCT     FOREIGN KEY (ENERGY_ACCOUNT_ID) REFERENCES CDP_APP.ENERGY_ACCOUNT(ENERGY_ACCOUNT_ID),
    CONSTRAINT FK_USAGE_PREMISE         FOREIGN KEY (PREMISE_ID) REFERENCES CDP_APP.SERVICE_PREMISE(PREMISE_ID),
    CONSTRAINT FK_USAGE_METER           FOREIGN KEY (METER_ID) REFERENCES CDP_APP.METER(METER_ID),
    CONSTRAINT CHK_KWH_NON_NEG         CHECK (KWH_USAGE >= 0),
    CONSTRAINT CHK_KW_NON_NEG          CHECK (PEAK_DEMAND_KW IS NULL OR PEAK_DEMAND_KW >= 0),
    CONSTRAINT CHK_BILL_DATES          CHECK (BILL_END_DATE > BILL_START_DATE),
    CONSTRAINT CHK_READ_TYPE           CHECK (READ_TYPE IN ('A','E'))
);
CREATE SEQUENCE CDP_APP.SEQ_MONTHLY_USAGE START WITH 1 INCREMENT BY 1 NOCACHE;
```

**Business key (MERGE key):** `(ENERGY_ACCOUNT_ID, BILLING_MONTH)` — correction handled by `SOURCE_UPDATED_AT` comparison.

## 5. Notes

- All `TIMESTAMP` columns store UTC values.
- `DATE` columns store business dates with no time component.
- Sequences are non-cached (`NOCACHE`) for demo simplicity; production should use `CACHE 20`.
- Partitioning by `BILLING_MONTH` on `MONTHLY_USAGE` is the designed scale-up path (Phase 7).
- Flyway migration scripts in `src/main/resources/db/migration/` will implement all DDL above.
